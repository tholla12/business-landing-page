# Golden Crust Bakery: Landing Page

A responsive, multi-section landing page for an imaginary bakery. Built to practise layout, accessibility and form handling with plain HTML, CSS and JavaScript.

**Live demo:** _add your GitHub Pages link here_

## Features

- Mobile-first layout using CSS Grid and Flexbox
- Mobile menu that opens and closes with JavaScript
- Menu, about, opening hours and order sections
- Order form with validation and clear error messages
- Accessible: skip link, labelled form fields, visible keyboard focus, semantic HTML

## Built with

HTML, CSS, JavaScript (no frameworks or libraries)

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

## What I learned

- Building a layout that works from 360px phones to wide desktops
- Writing my own form validation instead of relying on browser defaults
- Using ARIA attributes so the menu button and form errors work with screen readers
